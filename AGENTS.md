# Règles de vérification visuelle

- Pour ce projet uniquement, toute capture d’écran d’une page ou d’un élément de l’application doit être réalisée exclusivement dans le navigateur intégré de Codex.
- Toute capture d’écran doit impérativement utiliser une vue mobile ; ne jamais employer de vue ordinateur.
- Toute capture réalisée doit être intégrée directement dans la réponse finale de la discussion, en image Markdown avec son chemin absolu.
